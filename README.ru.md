# Items Network

Items Network добавляет в Factorio 2.0 кабельную систему виртуальной логистики предметов и жидкостей с поддержкой качества для предметов.

> Внимание: это бета-версия мода. Функциональность, баланс и интерфейсы могут меняться.

## Обзор

Мод позволяет строить локальные предметные сети на кабелях, подключать к ним терминалы и машины, забирать предметы из соседних сундуков и возвращать нужные ресурсы обратно в производство без длинных цепочек манипуляторов.

## Возможности

- Кабельная предметная сеть на основе `Network cable`
- `Network fluid intake pipe`, который забирает жидкости из подключенных труб в виртуальное хранилище
- `Network fluid output pipe`, который выводит выбранную жидкость из сети в подключенные трубы
- `Network terminal` с кастомным интерфейсом для просмотра и выдачи предметов
- **Вывод сигналов в сеть схем через терминалы для чтения содержимого сети**
- `Network buffer chest`, который запрашивает предметы из виртуального хранилища и возвращает мусорные слоты обратно в сеть
- Автоматическая подача предметов в машины из сетевого хранилища
- Полная поддержка качества в хранилище, запросах, GUI и подаче в машины
- Более равномерное распределение предметов по машинам, чтобы уменьшить простои и переполнение входов

## Сущности

- Network cable
- Network terminal
- Network fluid intake pipe
- Network fluid output pipe
- Network buffer chest

## Как это работает

1. Разместите сервер
2. Разместите сетевые кабели, чтобы собрать сеть.
3. Подключите `Network terminal`, чтобы получить доступ к общему виртуальному хранилищу.
4. сундуки автоматически подключаются к сети а сеть забирает из них предметы
5. Встройте network fluid intake pipe в линию сетевых кабелей и подключите к жидкостной трубе, чтобы импортировать жидкости в сеть.
6. Встройте network fluid output pipe в линию сетевых кабелей, выберите в его интерфейсе нужную жидкость и выводите ее в трубы.
7. Подключите производственные машины, чтобы сеть автоматически пополняла их входы.
8. Используйте network buffer chest, чтобы запрашивать точные предметы из виртуального хранилища.

## Поддержка качества

Предметы внутри сети учитываются вместе с их уровнем качества. Интерфейс терминала, логика подачи в машины и network buffer chest работают с качественными стаками, включая рецепты, которым требуется конкретное качество.

## Исследование и рецепты

Мод открывает свои устройства через технологию `Item network`. После исследования можно крафтить весь набор сетевых сущностей в логистической категории.

## Примечания

- Лучше всего подходит для компактных производственных районов, контролируемой подачи в машины и локальной логистики на кабелях.
