# Items Network

Items Network добавляет в Factorio 2.0 локальную кабельную систему виртуальной логистики предметов и жидкостей с поддержкой качества, подачей питания по сети и снабжением игрока.

> Внимание: это бета-версия мода. Функциональность, баланс и интерфейсы могут меняться.

## Обзор

Мод позволяет строить локальные предметные сети на кабелях, подключать к ним терминалы и машины, забирать предметы из соседних сундуков, передавать жидкости, возвращать нужные ресурсы обратно в производство без длинных цепочек манипуляторов.

## Как это работает

1. Разместите сервер - является корневым узлом сети
2. Разместите сетевые кабели, чтобы собрать сеть.
3. Разместите под сервером и подключаемыми машинами коннекторы
4. Терминал сети предоставляет доступ к инвентар сети и настройкам данной сети
5. Сундуки подключенные с помошью коннектора автоматически поставляют предметы в сеть
6. Жидкостные ввод/вывод соответственно взаимодействуют с сетью
7. Подключите производственные машины, чтобы сеть автоматически пополняла их входы и забирала результат.
8. Подключите турели, если хотите, чтобы сеть автоматически пополняла их боеприпасы.
9. Используйте буферный сундук сети, чтобы запрашивать точные предметы из виртуального хранилища.
10. После изучения технологии `Снабжение игроков` предметы запрашиваемые игроком будут поставляться из сети на той же поверхности.
11. Исследуйте `Электропроводность сети`, если хотите, чтобы сетевые кабели проводили электричество.
12. Производственный комбинатор позволяет установить предметы для производства и их максимальное количетсво, выдает сигналы соответствующие недостатку предметов

## Поддержка качества

Предметы внутри сети учитываются вместе с их уровнем качества. Интерфейс терминала, логика подачи в машины и network buffer chest работают с качественными стаками, включая рецепты, которым требуется конкретное качество.

## Примечания

- Лучше всего подходит для компактных производственных районов, контролируемой подачи в машины и локальной логистики на кабелях.
